# ☕ Aroma Café – Web Project

Sitio web estático de la cafetería artesanal **Aroma Café**, desarrollado como práctica de flujo de trabajo colaborativo con **Git Flow**.

## 🌐 Estructura del Proyecto

```
aroma-cafe-web/
├── index.html          # Página de inicio
├── menu.html           # Menú de bebidas y alimentos
├── login.html          # Formulario de acceso de clientes
├── contact.html        # Formulario de contacto
├── css/
│   └── styles.css      # Hoja de estilos global
├── README.md
├── CONTRIBUTING.md
└── .gitignore
```

## 🌿 Flujo de Ramas (Git Flow)

```
main          ─── Producción estable (v1.0.0)
develop       ─── Integración de funcionalidades
feature/*     ─── Desarrollo de nuevas páginas
hotfix/*      ─── Correcciones urgentes en producción
```

### Ramas del proyecto

| Rama                    | Descripción                                  |
|-------------------------|----------------------------------------------|
| `main`                  | Código en producción                         |
| `develop`               | Rama de integración                          |
| `feature/menu-page`     | Página del menú                              |
| `feature/login-form`    | Formulario de acceso                         |
| `feature/contact-page`  | Página de contacto                           |
| `hotfix/footer-phone`   | Corrección del teléfono en el footer         |

## 🏷️ Versiones

| Tag     | Descripción                          |
|---------|--------------------------------------|
| `v1.0.0`| Primera versión estable del sitio    |

## 🚀 Cómo ver el sitio

Abre `index.html` en tu navegador favorito o usa la extensión **Live Server** en VS Code.
